# Actions Rules — Members Page

Actions are available per row via the **Actions** dropdown button.

| Action | Current behavior | New design |
|---|---|---|
| Edit info | Redirects to member profile → Info tab | Keep |
| Merge duplicate member | Redirects to merge flow | Opens new merge modal with the member preselected — user only selects the target member |
| Edit role and memberships | Redirects to member profile → Roles tab | Keep |
| Edit payment details | Redirects to member profile → Pay/Bill tab | Keep |
| Edit limits | Redirects to member profile → Work Time & Limits tab | Keep |
| Enable tracking | Conditional — shown as disabled when tracking is already enabled. Behavior unknown | Keep |
| Reset password | Unknown | Keep |
| Remove member | Unknown | Keep |
